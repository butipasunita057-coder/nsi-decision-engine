# NSI 决策引擎

> 输入竞品 ASIN，输出红黄绿三色排序的改品清单，告诉亚马逊中小卖家**先改哪个、怎么改**。

---

## 🎯 项目定位

| 项目 | 说明 |
| ---- | ---- |
| **项目名称** | NSI 决策引擎（Net Sentiment Index Decision Engine） |
| **一句话定位** | 输入竞品 ASIN，输出红黄绿三色排序的改品清单，告诉亚马逊中小卖家先改哪个、怎么改。 |
| **目标用户** | 亚马逊中小卖家、跨境电商创业者、产品经理、Listing 运营 |
| **核心痛点** | 卖家手上有大量评论，但**不知道先改哪一项**；负面信息散落在数十上百条 review 里，没有优先级。 |
| **核心价值** | 把杂乱的评论信号转化为一份**有优先级**的改品清单：每个特征都给出"为什么是红色 / 怎么改 / Listing 怎么写"。 |

---

## 🚀 Demo 演示流程

1. 启动 App
2. 在页面上**选择**示例 ASIN，或在输入框**手动输入** ASIN
3. 点击 **Analyze** 按钮
4. 查看 **整体健康度评分**（0–100）与档位（健康 / 一般 / 危险）
5. 查看**红 / 黄 / 绿三色卡片**，按紧急度从上到下排序
6. **展开详情**，看到原始评论示例、问题诊断、推荐动作、Listing 改写建议
7. 卖家立即知道：**先改哪一个特征 → 怎么改 → 改完 Listing 怎么写**

## 🧮 核心算法

### NSI 公式（Net Sentiment Index，净情感指数）

```
NSI = (positive mentions − negative mentions) / total mentions
```

每一个产品特征（如"保温性能"、"杯盖密封性"）单独计算 NSI，取值范围 [-1, 1]。

### 红黄绿分类规则

| NSI 区间 | 颜色 | 含义 |
| -------- | ---- | ---- |
| `NSI < -0.5` | 🔴 红色 | 紧急修复 |
| `-0.5 ≤ NSI < 0` | 🟡 黄色 | 持续优化 |
| `NSI ≥ 0` | 🟢 绿色 | 保持卖点 |
| 数据缺失 / total ≤ 0 | ⚪ 灰色 | 数据不足 |

### 整体健康度评分

```
score = round((average_nsi + 1) × 50)
```

| 评分 | 档位 |
| ---- | ---- |
| ≥ 75 | 健康 |
| 50 – 74 | 一般 |
| < 50 | 危险 |
| 无有效数据 | 无数据 |

### P / L / S / M 归因

每条特征都会标注根因归属，便于卖家分工：

| 标签 | 含义 | 谁来改 |
| ---- | ---- | ------ |
| **P** | Product（产品端） | 工厂 / 研发 |
| **L** | Listing（页面端） | 文案 / 美工 |
| **S** | Service（服务端） | 客服 / 物流 |
| **M** | Malicious（疑似恶意评论） | 投诉 / 申诉 |

## 🛠 技术栈

- **Python 3.10+**
- **Streamlit**（单页交互式 Web UI）
- **本地 JSON**（`demo_data.json` 作为演示数据源）
- ❌ 无数据库
- ❌ 无爬虫
- ❌ 无登录 / 无鉴权
- ❌ 不调用任何外部 API

> 本 MVP 设计原则：**最小依赖、零后端、本地可跑**。

pip install -r requirements.txt

- Python 3.10 或更高
- Windows / macOS / Linux 任一

## 📊 演示数据说明

`demo_data.json` 包含 2 个示例 ASIN：

- `B0DEMO-CUP` — 不锈钢真空保温杯 500ml
- `B0DEMO-YOGA` — 高腰塑形瑜伽裤（女款）

每个 ASIN 各包含 6 个特征，覆盖：

- **三种颜色**：红 / 黄 / 绿
- **四种归因**：P / L / S / M

> ⚠️ **数据声明**
>
> - 本 Demo 使用**本地黑客松演示数据**，**不连接**真实亚马逊 API
> - **不爬虫**、**不抓取**任何亚马逊页面
> - **不存储**用户数据，**不收集**任何个人信息
> - 后续如接入真实评论数据集，会先经过隐私合规与数据脱敏审查
