# Echofy

> 把评论噪音变成改品优先级。
>
> 输入竞品 ASIN，输出红黄绿三色排序的改品清单，告诉亚马逊中小卖家**先改哪个、怎么改**。
>
> 项目名：**Echofy**（对外展示名）。MVP 内部代号为 NSI 决策引擎，技术文档与内部代码中可能依然出现此代号。

---

## 🎯 项目定位

| 项目 | 说明 |
| ---- | ---- |
| **项目名称** | **Echofy**（对外展示名；MVP 内部代号：NSI 决策引擎） |
| **公开指标名** | **Echo Score**（面向评委与卖家的评论健康度分数，内部计算函数仍为 `calc_nsi`） |
| **一句话定位** | 输入竞品 ASIN，输出红黄绿三色排序的改品清单，告诉亚马逊中小卖家先改哪个、怎么改。 |
| **目标用户** | 亚马逊中小卖家、跨境电商创业者、产品经理、Listing 运营 |
| **核心痛点** | 卖家手上有大量评论，但**不知道先改哪一项**；负面信息散落在数十上百条 review 里，没有优先级。 |
| **核心价值** | 把杂乱的评论信号转化为一份**有优先级**的改品清单：每个特征都给出「为什么是红色 / 怎么改 / Listing 怎么写」。 |

## 🚀 Demo 演示流程

1. 启动 App
2. 在页面上**选择**示例 ASIN，或在输入框**手动输入** ASIN
3. 点击 **Analyze** 按钮
4. 查看 **整体健康度评分**（0–100）与档位（健康 / 一般 / 危险）
5. 查看**红 / 黄 / 绿三色卡片**，按紧急度从上到下排序
6. **展开详情**，看到原始评论示例、问题诊断、推荐动作、Listing 改写建议
7. 卖家立即知道：**先改哪一个特征 → 怎么改 → 改完 Listing 怎么写**

## 🧮 核心方法论

### Echo Score（评论健康度分数）

> Echo Score 基于正负向评论提及差异和总提及量计算，用来衡量某个产品特征的评论健康度。

每个产品特征（如「保温性能」「杯盖密封性」「色号图片清晰度」）都会被单独打一个 Echo Score，取值范围 [-1, 1]，越接近 1 表示该特征评论越健康。具体公式请参考 [SPEC.md § 12](./SPEC.md#12-nsi--echo-score-计算规则)，不在本文作为对外宣传 headline。

### 红黄绿分类规则

| Echo Score 区间 | 颜色 | 含义 |
| -------- | ---- | ---- |
| `Score < -0.5` | 🔴 红色 | 紧急修复 |
| `-0.5 ≤ Score < 0` | 🟡 黄色 | 持续优化 |
| `Score ≥ 0` | 🟢 绿色 | 保持卖点 |
| 数据缺失 / total ≤ 0 | ⚪ 灰色 | 数据不足 |

### 整体健康度评分

所有有效 Echo Score 取平均后线性映射到 0–100：

| 评分 | 档位 |
| ---- | ---- |
| ≥ 75 | 健康 |
| 50 – 74 | 一般 |
| < 50 | 危险 |
| 无有效数据 | 无数据 |

### P / L / S / M 归因

每条特征都会标注根因归属，便于卖家分工：

| 标签 | 含义 | 谁来改 | 典型例子 |
| ---- | ---- | ------ | ------ |
| **P** | Product（产品本身问题） | 工厂 / 研发 | 杯盖漏水、缝线开线、续航虚标 |
| **L** | **Listing 页面表达问题** | 文案 / 美工 | **色号图片拍不清**、尺码表不准、主图色差 |
| **S** | Service（服务 / 物流问题） | 客服 / 物流 | 到货慢、外箱破损、售后不回 |
| **M** | Malicious（疑似恶意评论） | 品牌 / 申诉 | 同行刷评、引导购买竞品 |

> **L 归因是本项目发射点**：Listing 问题不需要改产品本身，不需要换工厂，只需要重拍图 / 重写文案，是性价比最高的改品动作。下面「演示数据」中的 `B0DEMO-BROW`（眉粉）就是一个典型 L 问题案例：产品本身可以，但色号图片与描述不准导致退货。

## 📊 演示数据说明

`demo_data.json` 包含 3 个示例 ASIN：

- `B0DEMO-CUP` — 不锈钢真空保温杯 500ml（P 主导：杯盖密封问题）
- `B0DEMO-YOGA` — 高腰塑形瑜伽裤（女款）（L+P 混合：尺码表 + 面料）
- `B0DEMO-BROW` — 双色长久不脱色眉粉（**L 主导**：色号图片拍不清、色号描述含糊，产品本身显色与持久度口碑在绿区）

每个 ASIN 各包含 6 个特征，覆盖：

- **三种颜色**：红 / 黄 / 绿
- **四种归因**：P / L / S / M

> **为什么加入眉粉这个案例？**
>
> B0DEMO-BROW 演示了一个典型场景：色号图片拍不清、色号名含糊，买家退货不是因为眉粉不好用，而是「收到的颜色和预期不一致」——这是一个 Listing 问题，不是产品问题。Echofy 会把它贴上 `L` 标签，建议交给美工重拍图 / 文案重写，而不是交给工厂返工。

亚马逊商家最容易误判的就是「以为产品不行」但其实是「页面没说清」。
